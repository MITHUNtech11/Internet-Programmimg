Evaluation Questions & Solutions (Marks Distribution: 20 Marks)

1. Explain the essential fields and HTML structure of the registration form. (6 Marks)

A well-architected registration form balances user experience with rigorous data integrity. The essential fields and structure comprise:

  • Semantic `<form>` Container: Utilizes method="POST" for secure payload encapsulation and novalidate when JavaScript intercepts submission to handle custom error styling.
  • Full Name (`<input type="text">`): Includes required, minlength="3", and autocomplete="name". Captures the identity of the registrant.
  • Email Address (`<input type="email">`): Leverages native RFC email syntactical validation and invokes the `@` keyboard layout on touch devices.
  • User Message (`<textarea>`): Captures multi-line textual feedback with defined rows, maxlength, and minlength constraints.
  • Explicit Form Controls: Submit (<button type="submit">) to trigger validation and submission, alongside Cancel/Reset (<button type="button">) to flush state gracefully.

2. Describe how to implement client-side validation using HTML5 and JavaScript. (8 Marks)

A resilient web client uses a hybrid approach combining HTML5 declarative constraints with JavaScript's programmatic Constraint Validation API:

  1. HTML5 Declarative Attributes: Setting attributes such as required, type="email", pattern, and minlength offloads basic parsing to the browser engine before any JavaScript executes.
  2. JavaScript Interception (`e.preventDefault()`): The form listener intercepts the submit event, halting the default HTTP dispatch until all validators evaluate to true.
  3. Regex & Boundary Evaluation: 
    const nameRegex = /^[A-Za-z\s]{3,50}$/;
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/;
  4. Dynamic Class Mutation: Toggling .is-valid and .is-invalid CSS classes dynamically highlights fields in green or red, accompanied by clear ARIA-compatible error notices.

3. Provide code snippets to illustrate the form design and validation implementation. (6 Marks)

// JavaScript Validation Logic
function validateEmail(email) {
    const re = /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/;
    return re.test(String(email).toLowerCase());
}

form.addEventListener('submit', (event) => {
    event.preventDefault();
    let isNameValid = /^[A-Za-z\s]{3,}$/.test(userName.value.trim());
    let isEmailValid = validateEmail(userEmail.value.trim());
    let isMsgValid = userMessage.value.trim().length >= 20;

    if (isNameValid && isEmailValid && isMsgValid) {
        showSuccessModal();
    } else {
        highlightFieldErrors();
    }
});

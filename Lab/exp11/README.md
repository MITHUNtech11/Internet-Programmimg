# Experiment 11: Interactive Web Page - Paragraph Appearance & Hover Highlighting

## Questions & Marks Distribution (10 Marks)
1. **Describe how to use JavaScript and CSS to change paragraph appearance on button click (4 marks)**
2. **Explain how to highlight specific words in a paragraph on hover using CSS/JS (3 marks)**
3. **Provide code to implement these features (3 marks)**

## Features
- Dynamic DOM class toggling (Theme, Typography, Font-family).
- Hover-activated keyword highlights with dynamic contextual popup tooltips.
- Live HUD tracking computed CSS properties in real time.

Answers to Questions (Marks Distribution: 10 Marks)

1. Describe how to use JavaScript and CSS to change the appearance of a paragraph on a button click. (4 Marks)

There are two primary paradigms in web engineering for mutating element styles on user events:

  • Class Mutation (Recommended): Using JavaScript's element.classList.toggle('class-name') to attach pre-defined CSS rules. This maintains strict separation of concerns between logic and presentation: 
    const para = document.getElementById('targetParagraph');
btn.addEventListener('click', () => {
    para.classList.toggle('high-contrast-mode');
});
  • Direct Inline Style Manipulation: Writing directly to the DOM style object via element.style.property = 'value' (e.g. para.style.fontSize = '20px').

2. Explain how to highlight specific words in a paragraph on hover using CSS or JavaScript. (3 Marks)

Specific words are wrapped inside inline <span class="highlight-word"> tags:

  1. Pure CSS Pseudo-Class (`:hover`): 
    .highlight-word:hover {
    background: linear-gradient(120deg, #f59e0b, #ef4444);
    color: #ffffff;
    border-radius: 4px;
    box-shadow: 0 0 12px rgba(245, 158, 11, 0.4);
}
  2. JavaScript Dynamic Tooltip: Listening to mouseenter and mouseleave events to dynamically position an informative tooltip over the hovered word based on element.getBoundingClientRect().

3. Provide the code to implement these features. (3 Marks)

// Word hover listener
document.querySelectorAll('.highlight-word').forEach(word => {
    word.addEventListener('mouseenter', (e) => {
        const rect = e.target.getBoundingClientRect();
        tooltip.style.left = `${rect.left + window.scrollX}px`;
        tooltip.style.top = `${rect.top + window.scrollY - 35}px`;
        tooltip.textContent = e.target.dataset.definition;
        tooltip.classList.remove('hidden');
    });
    word.addEventListener('mouseleave', () => {
        tooltip.classList.add('hidden');
    });
});

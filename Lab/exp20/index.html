Answers to Questions (Marks Distribution: 10 Marks)

1. Explain the logic for each operation. (3 Marks)

  • Factorial ($n!$): Mathematical product of all positive integers less than or equal to $n$. The boundary condition is $0! = 1$. The iterative algorithm initializes an accumulator at $1$ and multiplies by $i$ for $i \in [2, n]$.
  • Sum of Digits: Can be solved either via arithmetic modulo/division (extracting digits via n % 10 and reducing via Math.floor(n / 10)) or by converting the number to a string, stripping non-digit symbols, and accumulating the integer value of each character.
  • Palindrome String: A string that remains invariant when reversed. The optimal $O(n)$ two-pointer algorithm strips non-alphanumeric punctuation, normalizes case, and advances pointers from both ends (`left` and `right`) comparing characters until they meet.

2. Write reusable JavaScript functions for all operations. (4 Marks)

Implemented in external operations.js with return values:

// 1. Factorial
function calculateFactorial(n) {
    if (n < 0) return "Invalid input";
    let res = 1;
    for (let i = 2; i <= n; i++) res *= i;
    return res;
}

// 2. Sum of Digits
function sumOfDigits(num) {
    return String(num).replace(/\D/g, '').split('').reduce((sum, d) => sum + (+d), 0);
}

// 3. Palindrome Check
function isPalindrome(str) {
    const s = str.toLowerCase().replace(/[^a-z0-9]/g, '');
    return s === s.split('').reverse().join('');
}

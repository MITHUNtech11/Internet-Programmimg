Answers to Questions (Marks Distribution: 10 Marks)

1. Explain how DHTML combines HTML, CSS, and JavaScript for interactivity. (3 Marks)

Dynamic HTML (DHTML) is not a standalone programming language; rather, it represents the synergistic convergence of three core technologies:

  • HTML: Provides the structural Document Object Model (DOM) tree.
  • CSS: Defines stylistic presentation, keyframe animations, and transitions.
  • JavaScript: Acts as the event-driven procedural engine that queries the DOM and dynamically mutates attributes, styles, and animation classes without reloading the page.

2. Describe the implementation of hover-based background changes and window shake effect. (3 Marks)

  1. Hover Color Changes:

    Event listeners for mouseenter on colored square containers read custom data-color attributes and assign them directly to document.body.style.backgroundColor, smoothed by a CSS transition: background-color 0.4s ease rule.

  2. Window Shake Effect:

    Attaching a CSS @keyframes shake animation to the root container applies rapid alternating translateX(-10px) and translateX(10px) transforms. The "Stop Shaking" button removes the animation class.

3. Provide the code to achieve these functionalities. (4 Marks)

// 1. Hover color switcher
squares.forEach(sq => {
    sq.addEventListener('mouseenter', () => {
        document.body.style.backgroundColor = sq.dataset.color;
    });
    sq.addEventListener('mouseleave', () => {
        document.body.style.backgroundColor = '#090e17'; // default
    });
});

// 2. Window shake toggling
btnShake.addEventListener('click', () => {
    shakeWrapper.classList.add('is-shaking');
});
btnStopShake.addEventListener('click', () => {
    shakeWrapper.classList.remove('is-shaking');
});

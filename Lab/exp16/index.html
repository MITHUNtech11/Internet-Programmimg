Answers to Questions (Marks Distribution: 10 Marks)

1. Explain regular expressions and their importance in JavaScript. (3 Marks)

A Regular Expression (RegExp) is an object representing a formal sequence of characters defining a search pattern. They are fundamental in JavaScript engineering for:

  • Input Sanitization & Validation: Enforcing strict syntactic rules on user submissions (such as emails, telephone numbers, postal codes, and credit cards) prior to server dispatch.
  • String Searching & Substitution: Searching complex token sequences and replacing matching substrings via String.prototype.replace().
  • Performance: RegExp engines in modern V8/SpiderMonkey run compiled C++ native automata, delivering sub-millisecond pattern matching.

2. Write a regex pattern to validate passwords. (3 Marks)

A robust password validation regex pattern using positive lookahead assertions:

const passwordRegex = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]{8,}$/;

Pattern Anatomy:

  • ^ and $: Asserts beginning and end of string.
  • (?=.*[a-z]): Positive lookahead asserting at least one lowercase letter.
  • (?=.*[A-Z]): Positive lookahead asserting at least one uppercase letter.
  • (?=.*\d): Positive lookahead asserting at least one numeric digit.
  • (?=.*[@$!%*?&]): Positive lookahead asserting at least one special character.
  • {8,}: Minimum character length boundary of 8.

3. List and describe three methods of the RegExp object with examples. (4 Marks)

  1. `RegExp.prototype.test(string)`: Executes a search for a match between a regular expression and a specified string. Returns true or false. 
    const pattern = /\d{3}/;
console.log(pattern.test("Item 123")); // true
  2. `RegExp.prototype.exec(string)`: Executes a search for a match in a specified string. Returns a detailed result array containing the matched text, capturing groups, index position, and original input, or null if no match was found. 
    const pattern = /(\w+)@(\w+)/;
const match = pattern.exec("user@tech");
console.log(match[0]); // "user@tech"
console.log(match[1]); // "user" (group 1)
  3. `RegExp.prototype.toString()`: Returns a string representing the specified regular expression literal including its pattern and attached flags. 
    const regex = new RegExp("abc", "gi");
console.log(regex.toString()); // "/abc/gi"

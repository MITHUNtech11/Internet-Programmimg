Answers to Questions (Marks Distribution: 10 Marks)

1. Explain the DOM events onfocus, onblur, and onkeydown. (3 Marks)

  • `onfocus`: Dispatched when an element receives focus (via keyboard navigation via Tab or mouse click). Often used to show helpful hints, activate autocomplete menus, or apply distinct visual glows.
  • `onblur`: Dispatched immediately when an element loses focus. Essential for instant client-side field validation and hiding dropdown menus.
  • `onkeydown`: Dispatched the instant a physical keyboard key is depressed while the element is active. Unlike `input`, it captures navigation and system keys (ArrowDown, Escape, Enter).

2. Describe how AJAX can enable auto-complete. (3 Marks)

AJAX (Asynchronous JavaScript and XML) enables dynamic search querying without disrupting the user's active page state:

  1. Event Listening & Debouncing: The input listens to input or keyup events, buffering keystrokes with a 200–300ms debounce delay to avoid spamming network requests.
  2. Asynchronous Dispatch: Uses fetch('/api/search?q=' + query) or XMLHttpRequest to retrieve relevant JSON payload records from server endpoints or static storage.
  3. DOM Rendering: The returned records are dynamically formatted into an interactive <div class="suggestions-dropdown"> positioned beneath the input field.

3. Provide code to handle events and implement auto-complete. (4 Marks)

// 1. Handling DOM Events
input.addEventListener('focus', () => log('onfocus fired'));
input.addEventListener('blur', () => log('onblur fired'));
input.addEventListener('keydown', (e) => log(`onkeydown: Key=${e.key}, Code=${e.code}`));

// 2. AJAX Auto-Complete
async function searchTechnologies(query) {
    const res = await fetch('data.json');
    const data = await res.json();
    return data.filter(item => item.toLowerCase().includes(query.toLowerCase()));
}

searchInput.addEventListener('input', async (e) => {
    const q = e.target.value.trim();
    if (!q) return hideDropdown();
    const matches = await searchTechnologies(q);
    renderDropdown(matches);
});

Answers to Questions (Marks Distribution: 10 Marks)

1. Explain the structure of the registration form and required validations. (3 Marks)

The form captures diverse input primitives, each needing tailored validation rules:

  • Name (Text): String length >= 3, alphabetic characters and spaces only.
  • Age (Numeric): Integer parsing between 18 and 100 inclusive.
  • Address (Textarea): Minimum 10 characters to guarantee complete delivery information.
  • EmailID (Email): Syntactic validation against RFC 5322 regex pattern.
  • Hobby (Checkboxes): Requires at least one checked node across the checkbox node list.
  • Gender (Radio): Exactly one radio button must be active (`:checked`).
  • Country (Select): Value must not match default placeholder option (`value !== ""`).

2. Describe how to implement client-side validation using JavaScript. (3 Marks)

JavaScript intercepts the `submit` event via e.preventDefault(). A modular validation architecture checks each control independently:

  1. Query input references using document.getElementById or document.querySelectorAll('input[name="..."]:checked').
  2. Evaluate business rules using regex, length checks, and boundary logic.
  3. On violation, attach .has-error classes and expose associated error messages.
  4. On success, compile all validated attributes into a structured JavaScript Object for API dispatch.

3. Provide the code to validate the form. (4 Marks)

function validateForm() {
    let isValid = true;
    
    // Checkbox validation
    const checkedHobbies = document.querySelectorAll('input[name="hobby"]:checked');
    if (checkedHobbies.length === 0) {
        showError('grp-hobby');
        isValid = false;
    }
    
    // Radio button validation
    const selectedGender = document.querySelector('input[name="gender"]:checked');
    if (!selectedGender) {
        showError('grp-gender');
        isValid = false;
    }
    
    // Dropdown validation
    if (countrySelect.value === "") {
        showError('grp-country');
        isValid = false;
    }
    
    return isValid;
}

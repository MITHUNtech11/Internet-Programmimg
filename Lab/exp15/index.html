Answers to Questions (Marks Distribution: 10 Marks)

1. Explain the concept of the DOM and its role in dynamic content manipulation. (3 Marks)

The Document Object Model (DOM) is an in-memory, tree-structured object representation of an HTML document generated by the browser's rendering engine. Every element, attribute, and text snippet forms a distinct node.

  • Live Programmable Interface: Bridges HTML markup with programming languages like JavaScript.
  • Dynamic Content Manipulation: Enables modification of attributes, classes, content, and inline CSS in response to user events without re-fetching or reloading the document from the server.

2. Provide instructions for dynamically creating and appending elements. (4 Marks)

  1. Create: Use document.createElement(tagName) to instantiate an unattached element in memory.
  2. Configure: Assign attributes, IDs, classes, and text: 
    const card = document.createElement('div');
card.className = 'dynamic-card';
card.textContent = 'Asynchronously Generated Content';
  3. Attach / Insert: Target a parent container and append the new node:
    • parent.appendChild(card): Appends node as the last child.
    • parent.prepend(card): Inserts node as the first child.
    • referenceNode.insertAdjacentElement('beforebegin', card): Precise positioning.

3. Describe DOM traversal techniques with examples. (3 Marks)

DOM traversal allows navigating through relative nodes in the document tree:

Method / Property Direction Description
node.parentElement Upwards Returns the direct parent element node.
node.firstElementChild Downwards Selects first child ignoring whitespace/text nodes.
node.nextElementSibling Sideways Traverses to the immediate adjacent sibling following this node.
node.closest('selector') Upwards (Search) Traverses up ancestors to locate nearest matching selector.

Layout Principles & Questions (Marks Distribution: 20 Marks)

1. Explain the differences between fixed, fluid, and responsive layouts. (6 Marks)

Criteria Fixed Layout Fluid (Liquid) Layout Responsive Layout
Units Used Rigid pixel values (e.g. width: 960px). Relative percentages (e.g. width: 80%). Combination of fr, %, rem, clamp().
Behavior on Mobile Causes clipping and horizontal scrollbars. Shrinks proportionally; content becomes unreadably cramped. Reflows columns into single vertical stacks via media queries.
Behavior on Ultra-wide Leaves massive empty margins on sides. Stretches excessively; lines of text become too long to read. Caps container with max-width while adapting grid columns.

2. Describe the role of CSS (Flexbox and Grid) in creating adaptive layouts. (8 Marks)

  • CSS Flexbox (One-Dimensional): Designed for laying out items in a single row or column. It dynamically distributes available space, handles baseline alignment, and manages wrapping via flex-wrap: wrap. Ideal for navigation bars, button toolbars, and centered components.
  • CSS Grid (Two-Dimensional): Designed for complex multi-row and multi-column page compositions. Features like repeat(auto-fit, minmax(280px, 1fr)) calculate how many columns fit into the viewport dynamically without needing explicit media query declarations for every device size.

3. Provide examples of layout designs and how they adapt to different screen sizes. (6 Marks)

/* Responsive 3-Column to 1-Column Adaptation */

    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));

    flex-wrap: wrap;

    }

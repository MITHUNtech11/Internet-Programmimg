1. Explain the logic to compare two numbers and determine equality. (3 Marks)

Comparing numbers in JavaScript requires understanding type coercion, identity, and floating-point precision:

  • Strict Equality Operator (`===`): Compares both value and type without coercion. If either operand is of different types (e.g. 42 === "42"), it evaluates to false.
  • Loose Equality (`==`): Coerces operands to a common type prior to comparison, which can introduce subtle bugs.
  • IEEE 754 Floating-Point Precision: In JS, 0.1 + 0.2 === 0.3 is false due to binary floating-point rounding errors (results in 0.30000000000000004). The robust equality check uses Number.EPSILON: 
    function areAlmostEqual(a, b) {
    return Math.abs(a - b) < Number.EPSILON;
}

2. Describe how to search for a specific word in an array and return its index. (3 Marks)

To search for a word in an array, the process follows these algorithmic steps:

  1. Tokenization: Split the sentence string into an array of words using sentence.split(/\s+/).
  2. Index Lookup:
    • Array.prototype.indexOf(target): Returns the zero-based index of the first occurrence of the element, or -1 if the word is not found.
    • Array.prototype.findIndex(): Enables case-insensitive searches by passing a predicate function: 
      const idx = wordsArray.findIndex(w => w.toLowerCase() === target.toLowerCase());

3. Provide code snippets to implement both features. (4 Marks)

// 1. Number Equality Logic
function compareNumbers(a, b) {
    if (isNaN(a) || isNaN(b)) return "Invalid numeric input";
    if (a === b) return `${a} and ${b} are strictly EQUAL (===).`;
    return `${a} and ${b} are NOT EQUAL.`;
}

// 2. Word Search in Array Logic
function findWordIndex(sentence, targetWord) {
    const words = sentence.trim().split(/\s+/);
    const index = words.findIndex(word => 
        word.toLowerCase().replace(/[^a-z0-9]/g, '') === targetWord.toLowerCase()
    );
    return index !== -1 ? `Found "${targetWord}" at index [${index}] (Word #${index + 1})` : `Word "${targetWord}" not found.`;
}

# Experiment 06: Legacy Web Application Transition to HTML5

## Questions & Marks Distribution (20 Marks)
1. **Differences between earlier HTML versions and HTML5 (6 marks)**
2. **Features of HTML5 for web forms and development (8 marks)**
3. **Examples of HTML5 implementation in legacy application (6 marks)**

## Key Concepts Implemented
- Semantic structure: `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`
- Form controls: `email`, `number`, `date`, `color`, `range`, `<datalist>`, `<progress>`, `<meter>`
- Constraint validation: `required`, `minlength`, `pattern`, `min`/`max`
- Live state rendering without external dependencies.

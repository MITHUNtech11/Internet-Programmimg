Answers to Questions (Marks Distribution: 10 Marks)

1. Explain the concept of image toggling using JavaScript. (3 Marks)

Image toggling in JavaScript is the stateful alternation of visual assets on user interaction:

  • State Boolean / Counter: A variable (e.g. let isModeA = true) preserves the active state across clicks.
  • Source Mutation: Directly altering the element.src attribute (e.g. img.src = isModeA ? 'imgA.png' : 'imgB.png').
  • DOM Visibility Swapping (Modern): Keeping both image nodes preloaded in the DOM and toggling .active and .hidden CSS classes, which avoids network loading delays and layout flicker.

2. Describe how to change text style dynamically on hover. (3 Marks)

Dynamic text alterations can be accomplished via two methods:

  1. Pure CSS `:hover` Selector: 
    .text-hover-item:hover {
    color: #38bdf8;
    letter-spacing: 0.05em;
    text-shadow: 0 0 12px rgba(56, 189, 248, 0.6);
}
  2. JavaScript Dynamic Event Listeners: Listening for mouseover and mouseout allows computing dynamic coordinates, triggering external audio/analytics, or modifying styles programmatically.

3. Provide code examples for both functionalities. (4 Marks)

// 1. Image Toggle Logic
let isDay = true;
imageCard.addEventListener('click', () => {
    isDay = !isDay;
    imgA.classList.toggle('hidden', !isDay);
    imgB.classList.toggle('hidden', isDay);
});

// 2. Text Hover Style Logic
headline.addEventListener('mouseenter', () => {
    headline.style.color = '#f59e0b';
    headline.style.transform = 'translateX(8px)';
});
headline.addEventListener('mouseleave', () => {
    headline.style.color = '';
    headline.style.transform = '';
});

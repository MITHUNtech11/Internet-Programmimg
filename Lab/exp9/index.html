Responsive Design Principles (Marks Distribution: 20 Marks)

1. Explain the importance of responsive design for usability across devices. (6 Marks)

With global mobile traffic accounting for over 58% of all web interactions, responsive design is vital for modern software engineering:

  • Single Codebase Maintenance: Eliminates the costly and error-prone practice of maintaining separate desktop and mobile (`m.domain.com`) websites.
  • Usability & Ergonomics: Guarantees that touch targets are adequately sized for thumbs, fonts are readable without pinch-to-zoom, and content avoids horizontal overflow.
  • SEO & Core Web Vitals: Search engines like Google employ mobile-first indexing; responsive websites achieve superior search rankings and lower bounce rates.

2. Describe how media queries and responsive units are used in CSS. (8 Marks)

Responsive design relies on two foundational CSS mechanisms:

  1. Media Queries (`@media`): Conditional logic blocks that apply specific styles based on device capabilities: 
    /* Mobile first: base styles apply to phones */
.card-grid { grid-template-columns: 1fr; }

/* Tablet enhancement */
@media screen and (min-width: 768px) {
    .card-grid { grid-template-columns: repeat(2, 1fr); }
}

/* Desktop enhancement */
@media screen and (min-width: 1024px) {
    .card-grid { grid-template-columns: repeat(3, 1fr); }
}
  2. Responsive Units:
    • %: Relative to the parent element's dimensions.
    • em: Relative to current element or immediate parent's font size.
    • rem: Relative to the root (`<html>`) font size, avoiding compound scaling issues.
    • vw / vh: 1% of viewport width / height respectively.
    • clamp(MIN, VAL, MAX): Mathematically caps fluid values within accessible boundaries.

# Experiment 09: Responsive Web Design & Media Queries

## Questions & Marks Distribution (20 Marks)
1. **Importance of responsive design for usability across devices (6 marks)**
2. **Media queries and responsive units in CSS (8 marks)**
3. **Examples of responsive implementation techniques (6 marks)**

## Features
- Mobile-first CSS media queries (`min-width`).
- Fluid units: `%`, `em`, `rem`, `vw`, `vh`, and `clamp()`.
- Interactive mobile drawer menu with viewport HUD measuring screen widths and active breakpoints.

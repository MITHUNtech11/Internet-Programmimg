Answers to Questions (Marks Distribution: 20 Marks)

1. Explain the design elements (tables, lists, images) used for readability. (6 Marks)

  • Structured Tables (`<table>`): Ideal for comparing multidimensional tabular data (such as technical specifications, memory clock speeds, and benchmarks). Headers (`<th>`) with distinct styling give cognitive anchor points.
  • Bulleted & Numbered Lists (`<ul>`, `<ol>`): Breaks monolithic walls of text into scannable chunks, allowing users to quickly assess core features and sequential guides.
  • Semantic Visuals (`<img>`, `<svg>`): High-fidelity vector visuals provide immediate contextual cues without causing layout shifts when combined with explicit aspect ratios.

2. Describe the sequence of HTTP requests and responses for loading a webpage. (8 Marks)

  1. DNS Resolution: Browser maps hostname (e.g., `techflow.io`) to an IP address (`104.21.42.12`).
  2. TCP Connection Handshake: SYN -> SYN-ACK -> ACK establishes a reliable TCP socket over port 80/443.
  3. TLS Cryptographic Handshake: ClientHello, ServerHello, certificate validation, and key exchange establish symmetric encryption.
  4. Initial HTTP GET Request: Browser sends HTTP request for the base resource (`/index.html`).
  5. Parsing & Dependent Resource Discovery: Browser parses the received HTML DOM; encounters linked CSS, JS, and image tags.
  6. Multiplexed Asset Fetching: Under HTTP/2 and HTTP/3, secondary assets stream concurrently over the single connection.

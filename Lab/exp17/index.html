Answers to Questions (Marks Distribution: 10 Marks)

1. Describe the implementation of show/hide functionality with DHTML. (3 Marks)

Show/hide interactions are implemented by toggling the CSS display or opacity states via JavaScript listeners:

  • Display Property Approach: Toggling element.style.display = 'block' (Show) and element.style.display = 'none' (Hide). Completely removes the element from visual flow.
  • Class-Based Transition Approach (Modern): Toggling a CSS class .is-hidden that coordinates opacity: 0 and max-height: 0 with transition: all 0.3s ease for a smooth sliding fade.

2. Explain hover-based color changes using CSS and JavaScript. (3 Marks)

While CSS :hover operates on the hovered element itself, modifying an external ancestor like <body> requires JavaScript event listening:

  1. mouseenter fires when the cursor crosses into the square, setting document.body.style.backgroundColor = targetColor.
  2. mouseleave fires when the cursor departs, restoring document.body.style.backgroundColor = defaultColor.
  3. A root CSS rule transition: background-color 0.4s ease delivers gradual chromatic fading.

3. Provide the code for both features. (4 Marks)

// 1. Show / Hide Text Logic
btnShow.onclick = () => secretBox.classList.remove('is-hidden');
btnHide.onclick = () => secretBox.classList.add('is-hidden');

// 2. Hover and Restore Background Color
const defaultBg = '#090e17';
squares.forEach(sq => {
    sq.onmouseenter = () => document.body.style.backgroundColor = sq.dataset.color;
    sq.onmouseleave = () => document.body.style.backgroundColor = defaultBg;
});

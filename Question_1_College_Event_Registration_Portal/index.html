HTTP Request & Response Flow During Registration

When the student submits this form, the following client-server transaction takes place:

1
Form Data Serialization (Client)

The browser collects all input values, formats them into a multipart/form-data or application/x-www-form-urlencoded payload, and constructs an HTTP POST request header.

2
Transmission over TCP/IP

The request is transmitted to the web server (Apache in WAMP/LAMP at http://localhost/submit.php) on port 80 or 443.

3
Server Processing & Response

The server parses $_POST and $_FILES, validates business rules, stores records, and replies with HTTP/1.1 200 OK with an HTML receipt response body.
